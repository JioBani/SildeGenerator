# 0014. 사용자 모션그래픽 형식을 하나로 통합

Date: 2026-09-23
Status: Accepted

## Context

지식 설명, 교육, 캐릭터, 만화, 다큐 형식을 동일 대본으로 제작했지만 핵심 사건, 객체, 시간 구조와 기본 모션의 차이가 작았다. 이름별 고정 프레임은 장면 목적보다 표면 장식을 먼저 선택하게 했고 사용자 선택 비용만 늘렸다.

## Decision

- 사용자에게는 `모션그래픽` 형식 하나만 제공한다.
- 기존 형식의 유효한 차이는 장면별 내부 전략으로 이전한다.
- 내부 전략은 인과 설명, 순서 안내, 인물 반응, 상징 압축, 근거와 맥락이다.
- 화풍은 형식과 독립적으로 선택한다.
- 과거 작업의 장르 필드는 읽기 호환을 위해 보존하지만 새 요청에는 사용하지 않는다.
- 슬라이드 시네마틱은 정지 이미지 중심의 별도 엔진 축으로 유지한다.

## Consequences

- 사용자 화면과 새 제작 API에서 장르 선택이 제거된다.
- 감독 설계가 장면 기능과 주 전략을 명시해야 한다.
- 하나의 영상 안에서 여러 전략을 사용할 수 있다.
- `astra-motion`은 공개 모션그래픽 엔진이 되고 `genre-slide`는 내부 연구 호환 경로로만 남는다.
- 기존 다섯 형식의 결과물은 삭제하지 않고 비교 근거로 보존한다.
