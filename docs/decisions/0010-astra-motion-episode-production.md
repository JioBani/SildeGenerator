# ADR-0010: Astra 모션그래픽 에피소드 제작 경로

## 상태

채택. 첫 세로 경로가 mock 제작으로 검증되었습니다.

## 사용자 모델

사용자는 `에피소드`와 완성 영상만 봅니다. 제작 버전, 승인, 품질 검수, 전달 영수증은 복구와 감사에 필요한 내부 기록이며 일반 화면에 기술 용어로 노출하지 않습니다.

완성 에피소드 화면은 다음 행동만 제공합니다.

- 영상 재생
- 에피소드 영상 받기
- 결과 승인
- 수정 필요

## 실행 계약

`ScenePlan`은 장면마다 다음 감독 결정을 포함합니다.

- `scene_function`
- `layout`
- `object_states`
- `motion`
- `transition`
- `rhythm`
- `renderer_requirements`

Runner는 이를 `Scene Production Pack`으로 컴파일한 뒤에만 자산 제작을 시작합니다. `episode_60` 정책은 목표 50초, 계획 상한 54초, 실제 완성본 상한 60초이며 장면 10개, 발화 16개, 제작 자산 20개를 기본 복잡도 상한으로 둡니다. 실제 음성 길이가 60초를 넘으면 렌더 전에 중단합니다.

## 렌더와 검수

`astra-motion@0.1.0`은 HyperFrames 0.8.46과 GSAP 3.14.2를 Docker 이미지에 고정합니다. 장면의 배경, 제목, 근거 카드, 강조 오브젝트와 진행선을 독립 객체로 움직이며 마지막에는 정착 구간을 둡니다. 기존 `classic-slide`는 보존합니다.

검수 순서는 다음과 같습니다.

1. 대본과 감독 설계
2. 장면 계약
3. 미술과 구도 사람 검수
4. 모션·오디오 기술 검수
5. Gold 비교 사람 검수

기술 검사가 통과해도 자동 승인하지 않습니다. 결과는 `기술 검수 통과 · 디자인 검수 대기`가 되며, 사람이 승인하거나 수정 필요로 분류합니다.

## 내부 영속 기록

다음 구조는 화면에 노출하지 않고 내부에서만 작동합니다.

- `video_projects`
- `episodes`
- `production_versions`
- `approvals`
- `quality_reviews`
- `delivery_receipts`

검수와 영수증은 제작 버전별로 하나만 유지해 작업 재시도나 완료 이벤트 재전달이 중복 기록을 만들지 않게 합니다.

## 검증 결과

mock 이미지와 음성으로 `대본 입력 → 에피소드 생성 → Scene Production Pack → HyperFrames 렌더 → MP4 재생·다운로드 → 사람 검수`를 통과했습니다. 결과는 1920×1080 H.264/AAC였고, 내부 품질 게이트와 사용자 검수 상태가 함께 갱신되었습니다.

## 후속 범위

이번 결정은 한 편의 60초 에피소드 경로를 완성합니다. 여러 에피소드 자동 분할, 부모 프로젝트에서의 순서 관리, 검증된 완성본만 사용하는 전체 영상 결합은 다음 이식 단계에서 추가합니다.
