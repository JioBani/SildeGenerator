# 새 대본의 실행 가능한 의미 단위 검사

상태: **GOAL_NOT_MET**. 비공개 `hybrid-story@0.10.0` 개발 후보이며 운영 승격이 아니다.
목표는 특정 영상을 반복 재생하는 것이 아니라, 다른 대본에서도 정보의 관계를 정확히
시각화하고 비슷한 완성도를 얻는 것이다. 잘못된 계획을 거부하는 능력만으로 목표를
완료했다고 판정하지 않는다.

## 구현

- 실제 Core 분석 경로에 `semantic-sufficiency-0.1` 독립 평가를 연결했다.
  장면 제작 전에 대상·관계·상태가 충분한지, 경로·문법·원문 의미·인과가 맞는지 확인한다.
- 생성 감독과 다른 모델을 사용한다. 감독의 자신감이나 자기 승인 문구는 제외한다.
- 비트별 정확한 원문 인용과 수정 대상·재검사 범위가 없는 실패 판정은 승인에 쓸 수 없다.
- 원문을 유지한 수정만 기존 최대 3회 수리 예산에서 허용한다. 같은 계획을 그대로 다시
  평가하거나 동일 원인이 반복되는 경우는 중단한다. UNKNOWN은 자동 합격이 아니다.
- 대본·분석·기능 계약·평가 규칙·모델에 승인 기록을 결합한다. 직접 장면 계획 경로에서도
  일치하는 검수 기록이 필요하다. 반환 장면에는 Core가 검수 출처를 기록한다.
- 제공자 오류, 401, 과도한 출력, 180초 초과는 실패로 남긴다. 유료 API로 전환하지 않는다.
- 새 기능은 선택적 계약이다. 이전 공개 엔진과 기존 계약 시험을 보존했다.
  이전 비공개 소스는 `output/hybrid-story-0.9.1-baseline`에 남아 있다.

## 실제 구독 실행

| 시험 | 결과 | 호출 / 시간 |
| --- | --- | --- |
| 저수조 두 시점 수위, 전체 감독 계획 | 의미 검사 통과, 디자인 후보 3개 모두 실행 가능성 실패 | 5회 / 107.397초 |
| 이전 장난감 실패 계획 재평가 | 빈 도입·마무리 인과 장면 탐지, REVISE | 1회 / 18.864초 |

총 7회는 구독 경로 호출이다. 별도 유료 API·이미지·음성 호출은 모두 0회다.
위 시간은 각 실행의 경과 시간이며 전체 작업 시간이나 일반적인 성능 수치가 아니다.
각 시험을 한 번만 실행했고, 결과를 통과시키기 위한 재추첨을 하지 않았다.
모두 개발 증거이며 보류 대본 성적이 아니다. 새 최종 영상은 생성하지 않았다.

## 발견한 다음 병목

저수조 대본은 하나의 전후 수치 비교로 충분했다. 의미 분석은 그 관계를 보존했다.
그러나 콘셉트 생성기는 서로 다른 안을 만들기 위해 close/detail/wide 영화 스틸을
제안했다. 기존 계획에 영화 장면이 없는데 추가 이미지를 요구한 것이다.
독립 평가기는 ABC/CBA 양방향에서 세 안 모두 실행 불가로 판정했다.

이는 정보형 대본에서도 영화적 샷 차이를 요구하는 콘셉트 다양성 기준의 한계다.
불필요한 인물이나 영화를 추가해 통과시키지 않는다. 다음 개편에서는 실제 선택된
표현 경로 안에서 구현 가능한 디자인 차이를 계약화해야 한다. 도식의 배치·정보 위계·
강조 방식을 늘리려면 렌더러와 실제 프레임 검사를 함께 구현해야 하며, 이름이나 색만
다른 세 후보를 별개의 디자인인 것처럼 승인하지 않는다.

## 검증 범위와 남은 일

첫 관련 회귀 시험 67개 통과. 출력 제한 추가 후 확대 시험 85개가 46.503초에 통과했다.
겹치는 시험이므로 두 개수를 합산하지 않는다. 실행 명령은 연결된 학습 기록에 남겼다.
시험에는 검수 선행 순서, 실제 Core 연결, 원문 유지 수정, 동일 오류 반복, 평가 우회,
401, 잘못된 인용, 이전 계약 호환성이 포함된다. Mock 제공자 시험은 실제 영상 검수가 아니다.

아직 자동 대안 생성, 의미 평가의 대규모 부정 대조군, 보류 대본 성능, 전체 영화 독립 평가,
수정 횟수 감소와 새 대본의 동등한 영상 품질은 입증되지 않았다. 현재 6개 문법 외에
지도·공간, 전체·세부, 분해·재결합, 증거·판단을 실제 렌더 능력으로 확장해야 한다.
수치 전후 비교는 비수치 상태 변화나 인물 연기의 범용 구현이 아니다.
