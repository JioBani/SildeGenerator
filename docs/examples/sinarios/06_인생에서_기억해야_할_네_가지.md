# 인생에서 기억해야 할 네 가지 (00:33)

Four things to remember in life.

Number one: If you are right, don't waste time proving it to everyone.

Number two: If you are wrong, don't waste time pretending to be right.

Number three: If you need help, don't waste time to ask for it.

And number four: Always remember, life is too short.

Therefore, do not waste time on sadness and negativity.
