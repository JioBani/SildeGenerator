# 위치·영역 설명 문법 개발

전체 상태: **GOAL_NOT_MET**. `hybrid-story@0.11.0` 비공개 후보.
공개 Astra·슬라이드 엔진, 서비스 배포, 인증은 바꾸지 않았다.

## 실제로 추가한 능력

`map_spatial`은 이동 경로가 아니라 위치 관계를 설명한다. 서로 다른 이름의 지점 2~6개,
겹치지 않는 직사각형 영역 0~2개를 편집 가능한 객체로 만든다. 북·남·동·서와 영역 안·밖을
지원하며, 지점은 움직이지 않고 설명에 맞춰 등장·강조된다. 기존 지점은 계속 남아 비교 기준이 된다.

- `hybrid-scene-0.6` / `spatial-map-0.1` 계약과 전용 렌더러를 구현했다.
- 감독의 문법 목록·한계·고정 장면 설계 스키마·콘셉트 기능 설명에 연결했다.
- 동일 인물/그림을 돌려쓰지 않고 입력 지점·관계·영역으로 새 도식을 그린다.
- 원문에 없는 지점, 반대 방향 좌표, 대상 누락, 겹치는 글자 예상 영역, 경계선과의 충돌,
  관계보다 늦게 나오는 기준점, 짧은 읽기 시간을 차단한다.
- 원문의 이름만 포함하면 통과하는 허점을 막기 위해 관계를 직접 단정한 문장도 확인한다.
  현재는 명시적인 한국어/영어 단문만 지원한다. 부정·가정·암묵적 관계를 사실로 바꾸지 않는다.
- 실제 지도나 거리 척도인 척하지 않는다. `상대 위치 도식 · 거리 비례 아님`을 표시한다.
- 이전 장면 계약은 새 필드를 요구하지 않는다. 이전0.10 소스도 보존했다.

## 렌더 검증

세 대본의 좌표와 디자인은 기능 시험을 위해 직접 저작했다. 자동 감독이 전체 영상을
만든 증거와 구분한다. 로컬 한국어 음성의 실측 단어 시점에 관계 강조를 맞췄다.

| 개발 대본 | 표현 | 길이 | 프레임 |
| --- | --- | --- | --- |
| 공원 | 정문 북쪽의 연못, 연못 동쪽의 놀이터 | 14.542초 | 349 |
| 캠퍼스 | 도서관 서쪽의 연구실, 연구실 남쪽의 후문 | 14.750초 | 354 |
| 보호구역 | 영역 안 관측소, 영역 밖 주차장 | 14.667초 | 352 |

최종 영상: `output/spatial-map-dev-03/review.html`.
해상도1280×720, 24fps, 로컬 음성·자막 포함. 1,055프레임의 색상 표식에서 실제 위치,
등장 시점, 정지 유지와 관계를 측정했다. 보호구역 네 경계선도 실제 픽셀에서 확인했다.
좌우 반전·상하 반전·마지막 정지 화면·역재생 각 3개와 영역 경계선 제거 4개,
총16개 대조군을 거부했다. 이 작은 개발 대조군의 성적을 전체 평가 신뢰도로 확대하지 않는다.

Chromium의 실제 폰트 상자를 100ms 간격으로 검사해 세 영상의 글자 겹침·안전영역을
확인했다. 고의적인 자막 영역 침범도 탐지했다. 이는 최종 영상 OCR이나 모든 자막 픽셀의
검수를 대신하지 않는다. 대표 실제 프레임도 직접 확인했다.

## 실패에서 수정한 것

1. 문법을 추가하면서 감독 계약이 기존12,000자 한도를 넘었다. 한도를 올리지 않고,
   새0.6 계약의 중복 설명만 압축했다. 이전 계약은 유지했다.
2. 첫 렌더의 안내 문구가 안전영역을 약4px 넘었다. 문구를 위로 옮겨 장면별 한 번 재렌더했다.
   실패 출력은 `spatial-map-dev-02`에 보존했다.
3. 경계선 검사 초기 방식은 잉크 면적 비율을 사용해 가는 점선의 오른쪽 변을 잘못 거부했다.
   두께가 아니라 길이 방향의 점선 점유율을 측정하도록 바꾸고, 네 변 제거 대조군으로 재검증했다.
   초기 판정·계측값도 `spatial-map-dev-03/spatial-pixel-calibration.json`에 남겼다.

## 실제 감독 선택 시험

별도의 시험에서 동일 세 대본만 실제 생성 감독에 입력했다. 기대 문법·좌표·완성 도식은
전달하지 않았다. `gpt-6-sol / low`가 세 대본 모두 하나의 공간 설명 장면을 선택했고,
독립 `gpt-5.6-terra / low` 의미 검사도 통과했다. 구독6회, 45.534초였다.

이는 **의미 분석과 문법 선택** 증거다. 자동 좌표 저작·콘셉트 선택·렌더까지 이어진
전체 시험이 아니며, 이미 개발에 사용한 대본이라 보류 평가도 아니다. 기대 문법 일치를
곧 영상 품질로 간주하지 않는다. 해당 보고서의 일반 범위 문구보다 이 구분을 우선한다.

## 비용·검증·남은 범위

별도 유료 API0회, 생성 이미지0회, 로컬 음성3개. 로그인 변경과 외부 자료 구매 없음.
최초 사전 검사 실패1회, 세 장면 최초 렌더 후 각각 안전영역 수정1회. 모델 재추첨 없음.
Harness 검증과 관련 회귀102개가 통과했다(54.449초). 시험 명령과 증거 해시는
`experiments/meaning-planning-v1/spatial-map-learning.json`에 연결했다.

아직 실제 지리 좌표·복잡한 경계·거리·길찾기·중첩 영역·범용 자연어 공간 추론은 지원하지 않는다.
새 대본 전체 품질, 자동 설계된 좌표의 첫 시도 품질, 네 스타일의 완성 영상, 보류 대본 우세,
전체 영화 독립 평가도 남아 있다. 이번 능력을 전체 목표 완료나 HUMAN_APPROVED로 승격하지 않는다.

다음 핵심은 도식형 콘셉트가 불필요한 영화 장면을 요구하지 않도록 설계 선택지를 실행 능력과
맞추고, 자동 감독이 만든 장면까지 실제 출력 검사를 연결하는 것이다. 전체·세부, 분해·재결합,
증거·판단의 나머지 문법도 구현해야 한다.
