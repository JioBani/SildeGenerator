# 산소 5초 대본 · 다섯 장면 설계 제작 기록

> 2026-09-23 후속 판정: 이 비교는 다섯 형식의 독립성을 입증하지 못했다. 차이는 장면 전략과 표면 디자인으로 재분류했으며, 사용자 형식은 `모션그래픽` 하나로 통합했다. 결과물은 형식 템플릿이 아니라 비교 근거로만 보존한다. 상세 결정은 `unified-motion-graphics-research-2026-09-23.md`를 따른다.

## 판정

- 고정 장르 프레임을 재사용하지 않고 동일 대본을 다섯 개의 독립 장면 문법으로 제작했다.
- 모든 영상은 57.4초, 1920×1080, 30fps, H.264/AAC이며 음량은 -16.2 LUFS다.
- HyperFrames strict 검사에서 런타임, 레이아웃, 모션, 대비 검사를 모두 통과했다.
- 0.5초 이상 검은 화면은 없고 다섯 영상의 파일 해시는 모두 다르다.
- 독자 제작 SVG와 Windows 로컬 음성만 사용했다. 유료 이미지·음성 호출은 0회다.
- 기술 검수는 통과했지만 과학적 사실성과 최종 미술 품질은 사람 검수 대기 상태다.

## 공통 사건 분해

`가정 제시 → 오존 → 이동수단 → 건축물 → 지각·하늘 → 숨의 의미`

원문 순서와 내레이션을 동일하게 유지했다. 61.5초였던 로컬 음성은 원문을 자르지 않고 약 7% 가속해 57.4초로 정규화했다.

## 형식별 설계

| 형식 | 화면 판단 | 움직임 판단 | 검수 결과 |
|---|---|---|---|
| 지식 설명형 | 산소 부재 → 대상 → 상태 변화의 인과 도식 | 노드 순차 등장, 광선·균열·낙하 | 인과관계가 가장 직접적 |
| 교육형 | 여섯 관찰 항목과 현재 단계 강조 | 단계 활성화, 관찰 카드 진입 | 사용법이 아닌 단계별 관찰 수업으로 해석 |
| 캐릭터형 | O₂ 안내자가 사건을 보고 설명 | 시선 이동, 표정 변화, 팔 제스처, 몸통 호흡 | 진행자 역할은 읽히지만 정식 관절 리그는 아님 |
| 만화형 | 패널, 말풍선, 충격어로 사건 압축 | 패널 타격 진입, 충격어 팝, 사건 동작 | 다섯 형식 중 스타일 차이가 가장 강함 |
| 다큐형 | 가정·관찰 항목·재현 고지를 분리 | 느린 화면 접근, 자료 카드 등장 | 실제 관측 자료가 아님을 계속 고지 |

## 공통 객체 모션

- O₂ 분자와 지구: pulse와 settle
- 자외선: 경로 draw
- 오존 보호막과 건물: crack reveal
- 차량·비행기·인물·지각: 의미 방향을 따른 fall
- 건축물: dust release
- 마지막 숨: 반복 팽창과 안정

객체가 없는 장면에는 해당 모션을 등록하지 않는다. 이 규칙으로 기존의 `존재하지 않는 GSAP 대상` 경고를 제거했다.

## 남은 한계

1. 대본은 `산소 분자만 사라지는 가정`과 `산소 원자가 사라지는 가정`을 혼합한다.
2. 하늘이 완전히 검게 된다는 표현, 모든 이동 수단이 추락한다는 표현, 즉각적인 심각한 화상은 사실 검수가 필요하다.
3. 교육형은 절차 대본이 아니므로 행동 교육보다 관찰 순서 설명에 가깝다.
4. 캐릭터형은 분리 부품 애니메이션이지만 눈·입·팔을 포함한 정식 리그 자산은 아니다.
5. 이번 자산은 의도적으로 단순한 선형 도식이다. 최종 공개용 미술 품질 승인을 의미하지 않는다.

## 엔진 흡수 항목

- 장르 이름이 아니라 장면 기능에 따라 레이아웃과 모션을 작성한다.
- 원문은 공유하되 형식마다 별도의 정보 위계와 화면 구조를 가진다.
- 장면 객체 목록과 모션 대상 목록을 교차 검사해 존재하지 않는 대상의 모션을 차단한다.
- 실제 자료가 없는 다큐 재현에는 상시 고지 계약을 둔다.
- 렌더 전 음성 실측으로 60초 초과를 교정한다.
- `strict 검사 → 대표 프레임 비교 → 전체 렌더 → 음량·블랙 프레임·해시 검사` 순서를 제작 게이트로 사용한다.
