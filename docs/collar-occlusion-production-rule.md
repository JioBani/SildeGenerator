# 목은 옷 아래로: 레이어 가림을 제작 계약으로

## 전문 제작 방식에서 확인한 것

[Toon Boom의 Cutter 안내](https://helpcentre.toonboom.com/hc/en-ca/articles/45597694795155-How-do-I-mask-one-part-inside-another)는
가리는 대상과 가려지는 대상을 분리하고, 윤곽선을 별도 전면 레이어로 유지하는 구성을 설명한다.
채움과 선의 순서·안티앨리어싱 처리가 잘못되면 얇은 선이나 겹침이 생길 수 있다고 명시한다.
이 원리를 이번 장면에서는 **옷깃을 전면에, 연장한 목을 뒤에** 배치하는 방식으로 적용했다.

[Adobe의 캐릭터 원화 준비](https://helpx.adobe.com/adobe-character-animator/desktop/creating-and-controlling-puppets/prepare-artwork.html)는
머리·눈·눈썹·입 등의 구조와 이름, 독립 그룹과 연결점을 저작 단계에서 정하도록 안내한다.
즉, 잘린 PNG 몇 개만으로 리그가 완성되는 것은 아니다.

두 도구는 상용 도구다. 여기서는 문서의 제작 원리를 조사했으며 SDK를 복사하거나 설치하지 않았다.
오픈소스 저작 후보 Krita/OpenRaster, OpenToonz, Inochi2D의 비교는
`actor-assembly-reform-2026-09-24.md`에 이어진다.

## Astra의 구체 규칙

1. `motion_parent`와 `draw_order`를 별개로 지정한다. 머리를 따라 움직이는 목도 옷깃 뒤에 있어야 한다.
2. `covered_layer`, `occluder`, `overlap_extent`, `line_owner`를 접합별로 기록한다.
3. 목의 그림 끝은 보이는 피부 한가운데 두지 않는다. 옷깃 밑으로 충분히 연장한다.
4. 겹침 폭은 허용 회전과 이동의 극단 자세에서 정한다. 중립 자세에 맞는 최소 폭만 쓰지 않는다.
5. 목을 단색으로 보충하지 않고 같은 피부의 명암이 이어지는 자산을 저작한다.
6. 옷깃 선은 앞 레이어가 소유한다. 동일 윤곽을 두 장에서 중복 그리지 않는다.
7. 표정 승인 후에는 얼굴을 새 그림으로 바꾸지 않는다. 수정 범위만 합성하고 원본 얼굴과 비교한다.
8. 알파의 빈틈, 피부 영역의 배경 노출, 옷 위의 피부 침범을 각각 검사한다.
9. 공통 좌표 정합과 검수는 파일 해시에 묶는다. 다른 자세나 카메라에는 재사용을 보장하지 않는다.
10. 기술 검사 통과는 최종 디자인 승인이 아니다.

## 이번 D 실험 구현

- C 영상과 얼굴·표정 자산을 보존했다. 동일 내레이션과 시간표를 사용한다.
- 내장 이미지 편집 2회: 첫 목 연장은 폭이 부족해 왼쪽 틈이 남았다. 실패 영상을 `D/rejected-narrow-neck.mp4`로 보존했다.
- 두 번째는 옷에 가려질 넓은 피부 여유 영역을 만들었다. 기존 얼굴 자산은 그대로 두고 아래 목 부분만 사용한다.
- 머리 위쪽 특징점만 SIFT/RANSAC으로 정렬한다. 목 자체는 변경 대상이므로 정합 특징점에서 제외한다.
- 머리/목 그룹 뒤에 기존 몸통, 앞에 원래 몸통 그림에서 제한한 옷깃 영역을 배치한다. 옷깃은 새로 생성하지 않았다.
- 명암이 없는 단색 패치는 제거했다. 새 목의 끝은 앞쪽 옷 레이어에 가려진다.
- 기존 머리 회전 타이밍을 그대로 사용하며, 새 목은 같은 부모 변환을 따른다.
- `actor_assembly_gate.py`에 실제 가림 레이어 존재와 앞뒤 순서 검사를 추가했다.
- D 제작기는 렌더 전 가림 순서를 검사하고 렌더 후 `verify_light_pollution_collar.py`를 실행한다.
- 282프레임의 얼굴 비교, 지정된 옷깃 내부 두 영역의 배경 노출 여부, 디코딩 음성 동일성을 검사한다.

고정된 두 영역은 이 피부 팔레트·이 카메라·이 작은 움직임에 한정된 보조 검사다.
범용 피부 분류기나 전체 옷깃 경계 검출기로 표현하면 안 된다.
실제 옷깃 전체·손 접촉·큰 고개 회전은 별도 사람/확장 검수가 필요하다.
얼굴 영역의 프레임별 평균 채널 오차 허용값 1.5도 압축 차이를 위한 실험값이며 보편 품질 기준이 아니다.

## 검수할 것

- 옷깃 아래에 들어가는 목이 자연스러운가?
- 움직이는 동안 빈틈·피부의 옷 침범·이중 선이 없는가?
- 승인한 빛과 표정이 유지되는가?
- 목에 남은 국소적인 색·밝기 전환이 거슬리지 않는가?

서비스 자동 제작 경로는 변경하지 않았다. 별도 유료 API 호출은 0회다.
이번 구현은 작은 고개 회전 범위의 실험 리그이며 범용 연기 자산 승격은 하지 않는다.
