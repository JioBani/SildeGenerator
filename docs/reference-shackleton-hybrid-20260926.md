## 특히 중요한 두 발견

### 장면 사이 혼합뿐 아니라 장면 안에서 혼합한다

9~15초는 단순히 삽화 다음에 상자·화살표 도표를 붙인 화면이 아니다.
배경 지형은 유지되고 배는 배경과 다른 궤적으로 움직이며 점선이 공간 관계를 설명한다.
배경, 이동 객체, 설명 경로, 자막을 서로 다른 계층으로 저작하면 이 표현을 제어할 수 있다.
이것은 원본 레이어를 확인한 결과가 아니라 관찰한 출력을 재구현하기 위한 제안이다.

현재 `harness_sdk/hybrid.py`의 `HybridScene`은 cinematic/diagram/source 중 하나를 고르며,
diagram 데이터는 diagram 경로에서만 허용한다. 따라서 현 계약만으로는 회화적 배경 위의
독립 배 이미지와 지도 경로를 이 예시처럼 명시적으로 지정하기 부족하다.
기존 그래프의 `transport_track`이 있다는 이유로 이 능력이 완성됐다고 표시하지 않는다.

### 자연스러운 인상과 연속 관절 운동은 다르다

32.000~32.458초의 연속 프레임에서는 두 인물 자세가 겹쳐 보이는 중간 상태가 관찰된다.
두 자세 사이의 디졸브와 일치하는 시각적 증거이며, 실제 제작 알고리즘은 미확인이다.
완전한 골격 연기로 분류하지 않는다. 이 형식의 첫 구현에는 목적이 있는 정지 그림,
동일 인물의 제한적인 자세 전환, 배와 같은 객체 이동이 우선이다.
손과 물체의 지속 접촉 등이 필요할 때만 별도 리그 능력을 요구한다.

## 혼합형 개발 계획에 반영할 것

1. 장면의 전달 목적부터 선택한다: 인물의 경험, 공간·인과 이해, 자료 확인.
   문장마다 고정 비율로 세 종류를 순환하지 않는다.
2. 기존 독립 경로에 더해 장면 내부 합성 계약을 새 버전으로 설계한다.
   배경 이미지, 이동 객체, 경로, 앞뒤 가림, 자막 영역, 좌표계와 카메라 변환을 명시한다.
3. 움직일 배와 배경을 생성 전에 분리 계획한다. 원본 통 이미지에 배가 남은 상태로
   또 배를 겹치거나 이동 후 구멍을 노출하는 결과는 차단한다.
4. 지도는 지리 좌표와 삽화 좌표를 구분한다. 실제 항로인지 개념도인지 명시하고,
   경로가 육지를 통과하는지, 객체 방향과 경로 접선이 맞는지 확인한다.
   참고 영상의 12~14초에는 배가 밝은 육지처럼 보이는 영역과 겹친다.
   이것을 사실적으로 정확한 항해 규칙으로 복제하지 않는다.
5. 인물의 복장·얼굴·환경을 고정한 두 자세를 사용하고 짧은 상태 전환 후 유지한다.
   얼굴 이중상과 배경 흔들림을 검수한다. 디졸브를 모든 행동의 대용으로 사용하지 않는다.
6. 배 또는 인물 같은 주체와 팔레트를 장면 간 연결한다. 질감이 전혀 다른 일반 도표로
   갑자기 바뀌지 않도록 공통 디자인 기준을 적용한다.
7. 자료 화면과 설명용 재현은 별도 표기한다. 흑백이라고 실제 사료로 자동 분류하지 않는다.
8. 도입의 실패 질문을 결말의 목표 변화와 연결한다. 컷 전환은 사건 변화에 근거한다.
9. 이 참고는 90초다. 제품의 60초 제한은 바꾸지 않는다. 짧은 대본에서는 사건 수와
   자료 고지 분량을 다시 설계하며 단순히 전체를 1.5배 재생하지 않는다.

## 다음 검증 단위

- 독자 제작한 배경과 객체로 6초 내외의 `항로 -> 이동 -> 정착` 장면.
- 같은 인물의 `낙담 -> 판단 -> 결의` 두 자세와 짧은 유지 장면.
- 같은 주체와 톤을 유지하며 두 장면을 연결한 합성 결과.
- 실제 출력에서 배경 고정, 객체 독립 이동, 경로 정렬, 가림, 자막 안전 영역,
  얼굴 전환의 이중상을 각각 검사한다.
- 별도 대본으로 전이하기 전까지는 연구 후보로 유지한다.

순수 `narrative-slide`에는 이야기와 컷·카메라 원리만 참고한다.
객체·항로 합성과 정보 시각화는 별도 `hybrid-story`에서 개발한다.
