## Proposed bounded experiments

### Timing is separate from spacing

Current problem: adding frames or one generic easing curve does not establish readable acting.
Experiment: keep the approved character design and reaction event unchanged. Compare equal-duration motion with different spacing, then identical spacing proportions with different durations. Change only one variable per variant.
Record stimulus, gaze arrival, head onset, expression onset, hold and settle; sample displacement and velocity at output-frame resolution. These measurements describe motion, not whether it feels convincing.
Pass: target direction and identity remain correct, no unintended jump, and a human reviewer can identify what triggered the reaction. Preserve the best version.

### A metaphor needs an explicit mapping

Current problem: a decorative factory can obscure the GPU calculation relationship.
Experiment: map task to work item, processing unit to worker, and computed result to output. Preserve each task's identity through sequential and parallel variants. Mark the factory as an analogy, not literal hardware architecture or a promise that every calculation is parallelizable.
Record concept, visual representative, invariant, limits and possible misunderstanding.
Pass: a viewer can explain the intended relationship without inferring unsupported properties from the artwork.

### Select the rig for the required performance

Current problem: a technically valid puppet may still look rigid in a human reaction.
Experiment: compare an independent segmented reaction rig against the existing static character with the same stimulus and duration. Separate eyes, brows, mouth, head pivot and torso; avoid adding arm movement before the reaction reads clearly.
Counterexample: rigid timing may be desirable for a mechanical or deliberately awkward character.
Pass: human design/acting review remains mandatory. Do not automatically promote REACTION_READY or INTERACTION_READY.

## Contract mapping and next acceptance

Scene function determines the concept; design defines readable representatives; layout establishes relations; states encode causal changes; motion realizes those changes; transitions retain identity; rhythm allocates time for perception.
