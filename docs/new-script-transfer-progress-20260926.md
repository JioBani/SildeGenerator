# 새 대본 전이 시험과 정보 시각화 검사

상태: **GOAL_NOT_MET**. 비공개 `hybrid-story@0.7.0` 개발 경로다.
공개 Astra, 슬라이드 엔진, 인증, 서비스 배포는 변경하지 않았다.

## 품질 목표

- 다른 대본에서도 비슷한 전달력과 완성도를 얻어야 한다. 같은 그림에 음성만
  바꾸는 것은 전이가 아니다.
- 원인, 비교, 경로, 누적, 절차는 서로 다른 의미 계약과 출력 검사를 사용한다.
  미지원 문법을 분위기 이미지나 일반 확대 효과로 조용히 대체하지 않는다.
- 개발에 사용한 대본은 보류 세트로 재분류하지 않는다. 기술 통과, 의미 이해,
  디자인 품질, 관객의 감정 반응은 별도 평가다.

## 이번 실제 시험

기존 버스/자전거 비교와 다른 소재로 학교 정원의 물 모으기 대본을 추가했다.
10 + 20 + 15 = 45리터는 대본에 가상 예시임을 명시했다.
`experiments/meaning-planning-v1/development-water-script.txt`는 개발 세트다.

| --- | --- |

마지막 시도는 4회 구독 감독 호출, 428.243초이며 새 영상은 제작하지 않았다.
누적 도식과 선택 장면 오류를 고치는 동안 첫 두 의미 비트가 합쳐졌다.
이 후보를 제작 성공이나 전이 성공으로 승격하지 않는다. 계획 수정 한도를
소진했으므로 같은 입력을 무작정 다시 호출하지 않고 엔진/검사 결함을 수정했다.

## 구현한 개선

1. 기존 콘셉트·분석을 해시로 고정해 독립 평가만 다시 실행할 수 있다.
   평가 통과 후에도 입력·정책·원시 판정을 다시 확인한 뒤 장면 설계를 재개한다.
2. `concept-review-0.4`는 인용문을 근거 후보에서 선택하고, 실행 가능한 컷·시점·
   조명과 원본 의미 보존을 구분한다. 독창성 판정은 모방 요청 유무이며 법적 보증이 아니다.
3. `concept-consensus-0.2`는 전체 항목 일치율 90% 이상에 더해, 선택 후보의
   모든 항목과 선호가 양방향 모두 통과해야 한다. 불일치 탈락 후보는 격리한다.
4. 수치 문법에서 조건/면책 문구/합계만 분리한 비트를 사전에 거부한다.
   숫자 2개 이상 검사는 필요조건일 뿐 의미 정확성의 증명이 아니다.
5. 장면 검사는 `invalid_hybrid:diagram`만 반환하지 않고 위반한 규칙을 전달한다.
   입력 원문이나 예외 context는 되돌려 보내지 않는다.
6. `planning-repeat-stop-0.2`: 오류 집합 전체가 같아야 멈추던 결함을 수정했다.
   의미 분석을 사용하는 경로는 같은 원인이 연속 두 번 발생하면 다른 오류가
   추가/해결됐어도 중단하고 `planning-stop` 증거를 남긴다. 기존 경로는 유지한다.
7. 실제 출력의 비교 막대와 누적 트랙을 장면 수치·척도·색으로 검사한다.
   같은 색이 이어지는 누적 트랙은 개별 경계를 추정하지 않고 단계별 합계를 측정한다.
   마지막 총량만 맞고 중간량이 틀린 경우도 거부한다.

## 출력 증거와 검증

- 기존 비교 영상 365프레임: 막대 폭과 등장 시점 통과, 정지/역재생 대조군 거부.
  `output/meaning-film-design-01/numeric-general-audit.json`
- 기존 누적 영상 336프레임: 단계별 누적 폭 96/240/480px가 기대값과 일치.
  시작 정지, 완성 화면 고정, 역재생 3개 모두 거부.
  `output/semantic-diagrams-v03-run5/accumulation/numeric-general-audit.json`
- 이번 최종 집중 회귀 시험 83개 통과. 감독 MockTransport, 의미 구간, 기존
  프로토콜, 콘셉트 재개, 음성 단어 시점, 새 수치 검사 포함. Harness 검증 통과.
- 이것은 기존 영상 재검사이며 새로운 물 모으기 영상이 아니다. 픽셀 검사는
  OCR·사실성·정서·전체 미술 품질을 승인하지 않는다.

이번 조사/시험 묶음은 기록된 구독 호출 21회와 취소 당시 사용량이 확정되지 않은
요청 1건을 포함한다. 이미지 생성 0회, 음성 생성 0회, 별도 유료 API 0회.
취소 원본 receipt는 보존했다. 구독 사용량을 비용/사용량 0으로 표현하지 않는다.

## 다음 병목

고정한 의미 비트·관계·디자인을 장면 계획이 다시 작성하다가 훼손하는 병목이 크다.
선택된 계약은 Core가 소유하고 감독은 남은 연출 변수만 생성하도록 경계를 줄이는
개선을 우선 시험한다. 의미 누락, 숫자 왜곡, 원인 조작 검사를 약화해서 통과시키지 않는다.
이후 완성 영상 비교, 나머지 문법, 별도 보류 대본과 부정 대조군 검증이 남아 있다.

## 후속 결과

후속 비공개 `hybrid-story@0.8.0`에서 의미 비트와 디자인의 소유권을 분리했다.
같은 물 모으기 대본의 장면 설계가 1회 호출·수정 0회로 통과했고, 새 이미지와
로컬 음성을 이용한 33.875초 영상이 출력됐다. 이 문서 위의 실패 기록은 보존한다.
126개 회귀 시험 및 누적량 470프레임 검사를 통과했지만, 실제 화면의 문구 중복과
약한 인물 행동 표현이 남아 있다. 전체 품질·보류 대본 전이는 아직 합격이 아니다.
자세한 증거와 한계는 [후속 기록](locked-scene-design-development.md)에 있다.
