제공된 AUTO_RIG_SYSTEM_PLAN.md와 AUTO_RIG_SOURCE_MANIFEST.json을 읽고 반영했다. 원 자료 경로는 C:/Users/user/Documents/ai영상자동화/research/auto-rig-system-2026-09-25 이며 읽기 전용으로 유지했다.

- Animated Drawings는 전체 흐름 비교 기준, RTMPose는 검출 후보, SAM 2는 부위 마스크 후보, Rive는 후단 실행 후보로 평가한다.

- 1~2주/3~5주 등의 기간은 원 연구의 가설적 범위다. 인력·입력 품질·GPU·권리·리그를 확인한 뒤 계획을 다시 산정한다.

## 실행 구조

```text
이미지 + 감독의 명시적 행동 요청
  -> 입력 조건 검사
  -> 관절/객체 후보 + 불확실성
  -> 관절·마스크·앞뒤 순서 교정
  -> 독립 부위 + 가려진 영역 보완
  -> 표준 배우/리그 바인딩
  -> 지원 능력과 감독 의도의 일치 검사
  -> 검증된 동작 클립 + 고정 시간 렌더
  -> 기술 검수 / 사람 디자인·연기 검수
  -> 범위가 한정된 배우 등록
```

기존 이미지 분석 경로는 관절 분석과 교정, 명시 요청의 준비 경로 판정까지다. 별도 actor-motion-runtime 경로에서는 알려진 골격을 가진 공식/벡터 배우의 BVH 동작 실행이 가능하다. 두 경로가 자동으로 연결된 것은 아니다.

- [ ] 30~50장의 권리 확인 이미지를 쉬움/중간/어려움으로 나누고 튜닝 세트와 최종 평가 세트를 분리한다.
- [ ] 사람이 지정한 관절·마스크를 기준으로 저장한다. 모델 출력이나 합성 테스트를 정답으로 취급하지 않는다.

완료 기준: 입력마다 출처·권리·평가 범위가 있고, 미검출을 임의 좌표로 채우지 않는다. D/F 두 사례로 성공률을 주장하지 않는다.

## B. 관절 분석과 교정

- [x] 이미지 위 관절 드래그·숫자 입력·수정 사유·원본 복원을 구현한다.
- [x] 교정 기록을 이미지 해시와 분석 전체 해시에 묶어 내보내기/불러오기를 구현한다.
- [x] Python에서 교정값을 재검증하고 원시 관측을 보존하며 요청별 준비 상태를 재계산한다.
- [x] 다른 이미지/오래된 분석, 중복 관절, NaN, 잘못된 좌표, 승인 필드 삽입을 거부한다.
- [x] 미검출/다인 입력에서 현 교정 기능으로 임의 단일 배우를 만들지 못하게 한다.
- [ ] 미검출 입력의 사용자 인물 박스 지정과 재추론을 구현한다.
- [ ] 권리가 확인된 특정 RTMPose 체크포인트를 고정하고 MediaPipe와 비교한다.
- [ ] 모델별 confidence를 보정한다. 서로 다른 모델 점수를 무조건 평균내지 않는다.
- [ ] 관절별 수정 거리·횟수·실제 교정 시간을 기록한다. 단순 화면 체류와 작업 시간을 분리한다.

완료 기준: 오류를 수정할 수 있고 수정 이력을 재현할 수 있다. 좌표 교정은 디자인·연기 승인으로 승격되지 않는다.

## C. 부위 마스크와 가림

- [ ] 첫 범위를 팔 하나의 상완·전완·손·몸통으로 제한한다.
- [ ] 확정 관절에서 양/음의 프롬프트 점과 제외 영역을 만들고 사람이 수정할 수 있게 한다.
- [ ] SAM 2의 모든 후보와 선택한 마스크를 보존한다. 점을 주었다고 의미별 분리가 보장된다고 가정하지 않는다.
- [ ] 부위 누출, 끊김, 다른 물체 혼입, 합성 누락, 관절 겹침 여유를 검사한다.
- [ ] 마스크 편집, 앞뒤 순서, 접합부 확대 검수를 같은 화면에 추가한다.
- [ ] 동작 때 드러날 배경/몸통 영역을 계산하고 없는 픽셀은 추가 저작으로 보낸다.
- [ ] 생성 보완은 비용 승인과 입력·결과·생성 영역의 해시를 요구한다.

완료 기준: 중립 재조립과 시험 자세 전체에서 윤곽·빈틈·그림자·가림을 검사한다. 마스크 생성만으로 MOTION_READY를 부여하지 않는다.

## D. 배우·리그·실행기

- [ ] 수정 가능한 완성 리그 하나와 D/F 방식을 동일 동작으로 비교한다.
- [ ] 지역 좌표·부모·피벗·기준 자세·각도 제한·허용 시점·draw order를 기존 연구 ActorRig에 연결한다.
- [ ] 검증된 2-bone IK 구현을 선정해 도달 범위, 팔꿈치 방향, 뼈 길이, 접촉 유지 오차를 비교한다. 새로운 임시 솔버부터 만들지 않는다.
- [ ] idle/notice/reach/settle의 상태·시선·표정·팔 시간표를 분리하고 정의한다.
- [ ] 손가락은 별도 승인된 손 상태로 제한한다. reach 성공을 grasp 성공으로 확대하지 않는다.
- [ ] Rive 또는 기존 컷아웃 실행기를 고정 시간 제어·품질·통합 비용으로 비교한다.

완료 기준: 정방향/역방향/임의 프레임 출력이 재현된다. 같은 환경의 픽셀 결정성과 다른 GPU/브라우저 간 허용 오차를 분리해 측정한다.

## E. Astra 감독의 선택

- [x] 명시적인 행동·대상·목표·시간·이유를 검사하는 연구 라우터를 구현한다.
- [x] 팔·얼굴·물체의 준비 경로를 구분하고 미지원 동작의 자동 대체를 금지한다.
- [ ] 실제 감독 모델 출력에 요청 규격을 연결한다. 현 requests.json은 사람이 작성한 시험 입력이다.
- [ ] 대상 정체성·공간 관계로 후보 부위를 고른다. 검출 점수가 높은 팔을 의미와 무관하게 선택하지 않는다.
- [ ] 요청의 필요 레이어·접촉점·얼굴 상태와 배우가 실제 지원하는 능력을 비교한다.
- [ ] 수행 불가면 연출 변경 후보 또는 자산 보완 비용을 반환한다.
- [ ] 승인된 행동 클립을 검색하고 선택 이유·변경 파라미터·결과 프레임을 연결한다.

완료 기준: 무엇을 왜 움직였는지와 실제 실행이 대응한다. 자연어 계획을 지원 능력으로 오인하지 않는다.

## F. 검수·학습·제품 연결

- [ ] 기술/디자인/연기/이해도/권리를 별도 판정한다.
- [ ] D의 기존 자연스러움·목 접합 승인을 새 팔·좌표·리그에 상속하지 않는다.
- [ ] 동일 대본·음성에서 수정량·자연스러움·이해도를 기존 방식과 비교한다.
- [ ] 다른 이미지와 대본의 전이를 확인한 능력만 배우 장부에 등록한다.
- [ ] 작업 ID, 단계별 캐시·해시, 재시작 복구, 중복 실행 방지를 추가한다.
- [ ] 승인된 자산/행동 버전만 기능 플래그로 제품에 연결하며 기존 director_safety를 우회하지 않는다.

관절 오차/PCK는 인식, IoU는 마스크, 접합/접촉 오차는 실행 정확도를 측정한다. 자연스러움·감정 전달을 단일 자동 점수로 대신하지 않는다. 기술 통과율과 **오통과율**, 교정 시간, 재작업 횟수, 콜드/웜 시간 p50/p95를 함께 보고한다. 품질 문턱은 아직 벤치마크로 보정되지 않았다.

## 이번 검증과 남은 한계

18개 단위 검사와 9개 Playwright 검사를 통과했다. 숫자 수정·드래그·기록 왕복·stale 거부·미검출 차단·모바일 넘침·브라우저 오류를 검사했다. 다운로드한 시험 교정을 Python에 적용하고 원시 관측 보존/준비 상태 재계산도 확인했다.

브라우저 테스트의 교정 기록은 `AUTOMATED UI TEST ONLY`로 표시하며 사람 판정이나 학습 정답이 아니다. 사람 신원 인증이나 서비스 저장 API는 아직 없다. 현재 파일 기반 교정 기록이며 제작 승인 권한은 항상 false다.

위 교정 UI 검증 당시에는 기존 분석 JSON을 재사용했다. 추가 추론·이미지 생성·유료 API 호출은 0회였다. 이후 실제 동작 실행의 최신 상태는 문서 상단에 구분했다.
