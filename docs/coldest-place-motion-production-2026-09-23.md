# 우주에서 가장 차가운 곳: 모션그래픽 제작 기록

## 목적

사용자가 실제 서비스 화면에 과학 대본을 입력하고 `모션그래픽 0.4.0`을 선택하는 흐름부터 제작, 사람 검수, 수정까지 재현했다. 기술 검수 통과를 완성으로 오인하지 않고, 장면의 설명력과 고유한 움직임을 사람 검수 기준으로 삼았다.

## 사용자 흐름

1. 전체 입력을 사이트에 붙여 넣었다.
2. 그래픽 설명 화풍과 모션그래픽 구성을 선택했다.
3. 첫 제작은 기술 검수를 통과했지만 사람 검수에서 `수정 필요`로 판정했다.
4. 같은 대본으로 의미 오브젝트 기반 수정본을 제작했다.
5. 해상도, 프레임률, 음성, 길이, 음량과 장면별 시각 차이를 다시 검수했다.

## 제작 중 발견한 제품 문제

### 입력 정규화

- `[시나리오]` 제목과 선두의 `장르:`, `분량:` 메타데이터가 내레이션 장면으로 들어갔다.
- `273.15`의 소수점이 문장 경계로 잘렸다.
- 이를 제목/메타데이터/본문으로 분리하고 소수점 문장 분리를 보정했다.

### 실행 상태

- Runner 상태 확인이 매번 전체 harness 해시를 다시 계산해 시간 초과됐다.
- 불변 runner 이미지에서는 최초 로드 이후 검증된 harness를 캐시하도록 변경했다.

### 품질 판정

- 자동 초안은 반복되는 카드와 일반 배경 위주였다.
- 극저온, 느린 빛, 초유체라는 서로 다른 현상이 같은 표현 방식으로 축약됐다.
- 기술 검수 통과와 설명형 디자인 품질 통과를 분리해야 한다.

## 수정본 장면 설계

| 장면 기능 | 표현 전략 | 핵심 오브젝트 | 핵심 움직임 |
| --- | --- | --- | --- |
| 역설적 도입 | 증거/맥락 | 심우주, 지구, 실험실 | 우주에서 지구 실험실로 시선 유도 |
| 기준 설명 | 인과 설명 | 온도계, 분자, 0 K 기준선 | 온도 하강과 분자 운동 감소 |
| 인간의 개입 | 과정 안내 | 냉각 챔버, 레이저, 원자 | 레이저 수렴과 원자 집속 |
| 법칙 전환 | 상징 압축 | 규칙 도형, 뒤틀린 경계 | 익숙한 형태의 변형 |
| 느려지는 빛 | 직접 비교 | 빛 펄스, 달리기 선수 | 같은 축에서 이동 속도 비교 |
| 초유체 | 인과 설명 | 용기, 액체, 벽면 | 액체 상승 후 벽면 등반 |
| 결론 | 증거/맥락 | 실험실, 관측 신호 | 외계가 아닌 인간의 실험실로 귀결 |

## 검수 결과

- 길이: 57.2초
- 규격: 1920x1080, 30fps, H.264/AAC
- 음량: -16.1 LUFS, true peak -1.3 dBFS
- 유료 호출: 0회
- 첫 음성 실측 65초는 렌더 전에 차단됐다.
- 음성을 1.12배로 조정하고 장면 여백을 0.3초로 줄여 원문 의미를 유지한 채 60초 계약을 통과했다.
- 장면별 주동 오브젝트와 운동 방향이 구별된다.
- 디자인 색, 선, 타이포그래피와 정보 배치는 영상 전체에서 일관된다.

## 엔진에 흡수할 규칙

1. `장르`는 전체 영상을 고정하는 프레임이 아니다. 장면 기능이 표현 전략을 선택한다.
2. 각 설명 장면에는 대사 명사와 연결된 최소 한 개의 의미 오브젝트가 있어야 한다.
3. 각 장면에는 설명 관계를 드러내는 최소 한 개의 상태 변화가 있어야 한다.
4. 서로 다른 과학 현상을 동일 카드/배경 교체로 처리하면 사람 검수에서 실패한다.
5. 길이 검사는 음성 실측 뒤, 비싼 렌더 전에 수행한다.
6. 기술 검수와 사람의 설명력 검수를 별도 상태로 유지한다.
7. 수정본은 이전 후보를 덮어쓰지 않고 `best_so_far`와 비교한다.

## 남은 제품 작업

- 사이트의 `수정 필요` 상태에서 새 제작 버전을 연결하는 업로드/승격 경로가 없다.
- 현재 장면 전략을 실제 자동 ScenePlan 컴파일러로 승격해야 한다.
- 대본의 개념 명사와 SVG 오브젝트 사이의 대응을 자동 검수해야 한다.
- Mock 음성 예상 길이와 실제 로컬 음성 길이의 차이를 UI에 반영해야 한다.
