## Process finding

Deterministic rendering does not prove event presence. Pair seek checks with narrative-state assertions such as entry order, visible return flow and retained-object stability. Switch from one-second triage to native frames when an event starts and ends between adjacent samples. Keep source observations distinct from candidate timing hypotheses and preserve failed candidates as evidence.
