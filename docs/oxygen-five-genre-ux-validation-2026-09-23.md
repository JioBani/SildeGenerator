# 산소 5초 대본 · 5장르 사용자 경험 검증

> **철회됨 (2026-09-23).** 이 결과는 장르별 설계가 아니라 동일한 고정 프레임의 표면 변형에 가까웠다. 제품 샘플과 학습 성공 사례에서 제외했으며, 영상 파일도 회수했다. 아래 내용은 실패 원인과 당시 검증 범위를 보존하기 위한 감사 기록이다.

## 판정

- 사용자 화면에서 대본 입력, 장르 선택, 자동 화풍·렌더러 연결, 제작 진행, 완료 영상 재생까지 확인했다.
- 요청한 다섯 장르가 모두 42.267초, 1920×1080, 30fps, H.264/AAC 영상으로 완성됐다.
- 격리 환경의 이미지·음성 공급자는 모두 `mock`이었으며 외부 유료 호출은 0회다.
- 기술 경로는 통과했지만 모의 자산은 실제 캐릭터·과학 도식을 표현하지 않으므로 디자인 품질은 통과로 판정하지 않는다.
- 대본은 과학적 가정과 사실을 혼합하고 있어 지식·교육·다큐 장르의 실제 제작 전 사실 검수와 문구 수정이 필요하다.

## 사용자 흐름

1. 접근 토큰과 동일한 대본을 입력한다.
2. 장르를 선택한다.
3. 장르가 기본 화풍과 `genre-slide@0.3.0`을 자동 선택한다.
4. `영상 만들기`를 누르면 60초 에피소드 작업이 시작된다.
5. 화면에서 진행 단계와 장르·화풍·렌더러를 확인한다.
6. 완성 후 영상 재생, 다운로드, 승인 또는 수정 필요를 선택한다.

첫 지식 설명형은 브라우저 화면에서 전 과정을 직접 확인했다. 교육형·캐릭터형·만화형·다큐멘터리형은 같은 공개 API와 격리 제작 대기열을 순서대로 통과시켰다. Playwright 장르 선택 회귀 검사도 별도로 통과했다.

## 시험 중 발견하고 고친 문제

1. 서버 장르 목록에는 캐릭터형이 있었지만 Python 러너 입력 계약에 빠져 첫 요청이 422로 거절됐다. 두 계약을 맞추고 전체 장르를 순회하는 검사를 추가했다.
2. 캐릭터형 설명 상자의 대비가 2.85:1로 최소 검사 기준 3:1에 미달했다. 짙은 단색 배경으로 바꿔 엄격 검사를 통과시켰다.
3. 실패 메시지가 한 차례 `[object Object]`로 축약됐다. 입력 검증의 구조화된 오류도 JSON으로 보존하도록 HTTP 러너를 수정했다.
4. 모의 자산은 흐릿한 추상 도형이라 장르별 레이아웃은 비교할 수 있지만 캐릭터 연기·과학 정보 전달·다큐 증거성을 판단할 수 없다.

## 내용 검수

- 지각에서 산소가 차지하는 질량 비율 약 46.6%는 USGS 자료와 부합한다.
- 산소만 사라져도 질소가 남기 때문에 하늘이 즉시 완전히 검게 된다는 문장은 성립하지 않는다. NASA는 질소와 산소를 모두 레일리 산란의 주요 원인으로 설명한다.
- 오존이 사라지면 위험한 자외선 노출이 늘어나는 방향은 맞지만, 5초 만에 모든 야외 생명체가 심각한 화상을 입는다는 단정은 근거가 부족하다.
- 산소 원자가 사라진다는 가정과 산소 분자만 사라진다는 가정이 대본 안에서 섞여 있다. 콘크리트와 지각 장면은 이 둘을 구분한 뒤 다시 써야 한다.
- 내연기관의 연소 중단은 타당하지만 모든 이동 수단이 동력을 잃고 추락한다는 표현은 전기 교통수단과 활공 상태 등을 무시한 과장이다.

따라서 실제 공개 영상으로 전환할 때는 이 결과를 `TECHNICAL_PASS_HUMAN_PENDING`으로 유지하고, 사실 수정 대본과 실제 디자인 자산으로 다시 제작해야 한다.
