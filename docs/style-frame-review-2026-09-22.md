# First cinematic style-frame comparison

Scope: same GPU story moment, a person noticing a generated image on a monitor.
These are style samples, not canonical rigs or proof of multi-cut consistency.

## Generation

Built-in image generation: three calls (cute draft, fantasy draft, cute revision).
No application image provider or separate API-key workflow invoked. This does not
assert subscription billing or a monetary cost from missing billing evidence.
Final candidate files live in web/public/style-previews, not only the tool cache.

## Visual observations

- Cute V1: insufficient distinction from the anime candidate, overly detailed background;
  unrequested sleeping cat appeared outside the monitor. Not selected for UI.
- Cute V2: rounded head, simpler hands, broad mint/coral/jade color blocks, sparse room.
  Extra cat removed. Readable face and monitor; lower desk area leaves caption space.
  Gaze direction is approximate with dot eyes; the result is still a static pose.
- Fantasy V1: more natural proportions, fine line and cel-shaded face, painted background.
  Monitor subject and face are readable. Lamp overlaps monitor corner and one hand supports
  the chin despite requested hands at desk. This is a useful style example, not an exact
  blocking/pose contract pass. It does not prove fantasy environments or acting quality.

## Learning retained

The cute preset now explicitly limits background detail and prohibits extra companion
animals/people absent from the script. The user can compare actual example artwork by
changing the style selector. Examples are labelled pending continuity review.
