# 빛 공해 1분 모션그래픽 벤치마크

## 판정

`TECHNICAL_PASS / HUMAN_DESIGN_REVIEW_REQUIRED`

이 영상은 현재 고정된 HyperFrames 0.8.46 + GSAP 3.14.2 런타임으로 만든 **수동 저작 감독 벤치마크**다. 대본을 사이트에 넣고 자동 ScenePlan, 이미지 공급자, 작업 큐를 거치는 E2E가 아니다. 인물 관절 리깅, AI 이미지 분해, 범용 감독 능력의 통과 증거로 승격하지 않는다.

## 입력과 사실 검수

주제와 이야기 순서는 사용자의 대본을 따른다: 밤하늘의 상실 → 인구 규모 → 빛 확산 → 야생동물 → 인간의 수면 → 조명 선택과 별빛. 음성은 로컬 Microsoft Heami Desktop으로 만들고 원문을 의미 범위 안에서 압축했다. 2016년 [World Atlas](https://doi.org/10.1126/sciadv.1600377)의 80% 이상은 **빛 공해가 있는 하늘 아래 사는 인구**로 표현했다. 은하수를 못 보는 인구와 혼동하지 않았다. 야생동물 예시는 [DarkSky의 생태계 자료](https://darksky.org/resources/what-is-light-pollution/effects/wildlife-ecosystems/)를, 멜라토닌 표현은 [인간 건강 자료](https://darksky.org/resources/what-is-light-pollution/effects/human-health/)를 참고하되 일반적인 실외 조명이 모든 사람에게 질병을 일으킨다는 단정은 피했다.

## 제작 계약

| 장면 | 기능 | 움직이는 정보 |
| --- | --- | --- |
| 1 | 질문 | 도시의 빛 번짐이 커지며 별 가시성이 감소 |
| 2 | 근거 | 80% 이상 원형 비율이 그려지고 도시/어두운 하늘을 비교 |
| 3 | 원리 | 등불의 상향 광선이 대기에서 퍼지고 별이 희미해짐 |
| 4 | 생태 | 원래 경로와 인공조명 쪽 경로가 갈라지고 새·거북 이동 |
| 5 | 인간 | 창으로 들어오는 빛과 수면 신호의 약화 |
| 6 | 선택 | 빛 번짐이 줄고 은하수·별이 나타남 |

장면별 SVG 객체는 원본 저작이며 시간표는 실측 음성으로 결정한다. 편집 가능한 객체 이동·경로·상태 변화가 주동작이다. 전체 이미지 흔들기나 동일 카드 등장 반복을 주동작으로 사용하지 않았다. 별도 유료 이미지·음성 API 호출은 0회다.

## 실행과 수정 기록

1. 로컬 음성 초안 62.69초가 60초 계약을 초과했다. 최종 문장을 압축하고 1.20배 음성 속도로 다시 실측해 59.22초 제작 시간표를 얻었다. 음성 초과 상태에서는 렌더를 시작하지 않았다.
2. 첫 렌더 시 HyperFrames 임시 프레임이 여유 없는 C 드라이브에 저장돼 시작 전에 차단됐다. 해당 작업만 D 드라이브 임시 경로를 지정해 복구했다. 사용자 파일은 삭제하지 않았다.
3. V1 프레임 검수에서 도시 실루엣이 비교 화면의 어두운 절반까지 넘어갔다. 도시 절반에 명시적 SVG clipPath를 추가했다.
4. V1에서 새와 거북의 기존 SVG transform과 GSAP 이동이 충돌해 화면 밖으로 잘렸다. 기준 위치를 부모 그룹에 고정하고 움직이는 자식 그룹을 분리했다. V1 파일을 보존하고 V2에서 수정했다.
5. V2 음성의 평균 크기가 -21.34 LUFS여서 영상은 그대로 두고 음성만 정규화했다.

## 품질 한계와 엔진 학습

- 정보 흐름과 색·선의 일관성은 자체 검토에서 읽힌다. 이는 시청자 이해도 검사가 아니다.
- 도시·동물·침실 그림은 단순한 도식이며, 캐릭터 연기나 고급 일러스트 자산의 품질을 입증하지 않는다. 특히 거북 그림과 수면 신호는 추가 미술 검수가 필요하다.
- 로컬 음성은 명료하지만 자연스러운 인간 내레이션과 동일하지 않다. 문장 단위 자막 동기화, 음악과 효과음은 이번 시험 범위 밖이다.
- 벤치마크를 제작하려면 사람이 여섯 장면의 기능, SVG 오브젝트와 움직임을 직접 써야 했다. 현재 자동 감독과 일반 Scene Program만으로 동일 결과를 재현할 수 있다고 주장할 수 없다.
- 다음 엔진 계약 후보: `motion_target`의 기준 좌표계/피벗을 필수화하고, `clip_region`을 별도 필드로 저장하며, 대표 프레임에서 객체의 화면 밖 이탈을 사전 검수한다. 임시 렌더 저장소를 용량 검증 뒤 고르고, 실측 음성 60초 게이트와 음량 정규화를 제품 경로에서 확인한다.
- 이 후보는 본체 자동 규칙으로 승격하지 않았다. 다른 대본의 두 번째 장면에서 같은 계약을 시험하고, 실제 제작 경로와 사람 검수를 통과한 뒤에 승격한다.

## 재현

`scripts/build_light_pollution_motion.py`의 `prepare → build → render` 순서다. `prepare`가 내레이션 장부를 만들고, 로컬 음성 합성 뒤 `build`가 프로젝트/시간표를 만든다. `render`는 핀 고정 런타임으로 프레임을 합성하고 영상과 정규화 음성을 결합한다. 입력 음성·코드·결과 해시는 결과 폴더에서 추적할 수 있다.
