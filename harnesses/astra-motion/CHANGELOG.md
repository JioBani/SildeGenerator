# Changelog

## 0.9.1

- 로컬 내러티브에서 스포트라이트 효과와 선택적 주의를 별도 주제로 분리합니다.
- 옷 자국, 상상 속 시선, 타인의 실제 관심, 이완을 장면별 편집 가능 객체와 동작으로 구성합니다.
- 기존 0.9.0 출력은 보존하고 새 작업에서만 변경된 장면 프로그램을 사용합니다.

## 0.9.0

- 격리 시험용 비용 없는 로컬 그래픽과 한국어 음성 제작 경로를 추가합니다.
- 내러티브형은 반복 등장하는 제한형 벡터 인물의 시선·표정·몸짓과 사건 대상을, 교육·정보형은 편집 가능한 단계·관계 도식을 실제 프레임에 출력합니다.
- 이 경로는 AI 이미지나 승인된 배우 리그가 아니며, 원격 이미지 인증이나 유료 API로 자동 전환하지 않습니다.

## 0.8.0

- 모션그래픽 제작 스타일별 감독 지침·장면 계약·렌더 처리를 추가합니다.
- 교육·정보형 레이블은 생성 이미지가 아닌 편집 가능한 DOM 객체로 출력합니다.
- 새 스타일에서는 의미 없는 기본 카메라 줌을 제거하고, 배우·접촉 자동 승격은 계속 차단합니다.

## 0.7.0

- 감독이 장면을 설계하기 전에 실제 지원 문법과 자산 경로를 받는 계획 계약을 추가하고, Harness snapshot과 함께 보존합니다.
- 계획 계약의 효과 목록은 감독 출력 스키마와 일치시켰고 `diagram` 레이아웃을 구조화된 출력에서 허용합니다.
- 배우 자산·표정·접촉 능력은 요구 사항으로만 기록하며, 제작 승인이나 품질 통과로 취급하지 않습니다.

## 0.6.0

- 모션 장면의 지원 레이아웃·전환·리듬·동작과 독립 대상의 영역·분리 계획을 이미지·음성 생성 전에 검증합니다.
- 배우 반응과 리그 기능은 외부 검수 요청이 없는 일반 효과로 조용히 대체하지 않습니다. 기존 영상 파일은 변경하지 않으며, 이전 버전 작업 재시도에는 해당 버전의 실행 이미지가 필요합니다.

## 0.5.0

- 생성 이미지의 의미 객체를 로컬 마스크와 RGBA 레이어로 분해하는 계약을 추가했습니다.
- 제거된 객체 뒤의 clean plate를 만들고 원본·마스크·배경·품질 지표를 장부에 남깁니다.
- 사람 승인 전 레이어의 자동 제작 투입을 차단했습니다.
- 실제 이미지 레이어는 도형 오버레이보다 작은 이동 예산을 사용하며, 배경과 좌표가 어긋나는 독립 카메라 이동을 금지합니다.

## 0.3.0

- 장면 기능·레이아웃·객체 역할·모션·전환·리듬을 allowlist 기반 Scene Program으로 컴파일합니다.
- 모든 장면에 같은 장식과 타임라인을 강제하던 고정 템플릿을 역할 기반 구성으로 변경합니다.
- 실제 vertex/triangle에서 displacement, edge stretch, area ratio, triangle flip, seam gap, neutral 복원을 계산하는 limited mesh v2 증거 계약을 추가합니다.
- Blender와 OpenToonz는 자동 런타임이 아닌 Gold authoring/reference 도구로 분리합니다.

## 0.2.0

- 실험 기능을 기본 거부하고 외부 사람 승인과 현재 계약 해시가 일치할 때만 허용합니다.
- 제한 메시, 인물 반응, 접촉 연기, 자산 성숙도, 렌더러 승격, 이론 규칙 승격을 독립 capability로 분리합니다.
- Astra Harness를 명시적으로 선택하는 실험 경로로 표시하고 기본값은 classic-slide로 복원합니다.
- `INTERACTION_READY`는 전역 자산 상태가 아니라 현재 제작 버전에 한정된 승인으로만 취급합니다.

## 0.1.0

- 실행 가능한 장면 계약을 GSAP timeline으로 컴파일합니다.
- HyperFrames 결정론적 MP4 렌더를 추가합니다.
- 오브젝트별 등장, 이동, 강조, 정착 단계를 기록합니다.
- 결과를 기술 통과·사람 Gold 검수 대기로 분리합니다.

## 1.1.0

- 장면 계획에서 런타임 ID와 교차참조 생성을 제거하고 결정론적 컴파일러 계약을 사용합니다.
- 모델은 중첩된 의미 구조와 장면 번호만 제안하며 source unit, hierarchy, keycut parent, continuity 참조는 Core가 생성합니다.

## 1.0.0

- 기존 24fps Ken Burns/crossfade/ASS 자막 렌더를 Core `media.py`에서 Harness로 이전했습니다.
- 임의 DAG의 subtitle/render/audio/assembly task로 실행됩니다.
